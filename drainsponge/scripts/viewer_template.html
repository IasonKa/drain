What is computed here, and what the package contains

This viewer shows the reduced-order model (axisymmetric, linear poroelastic sponge + lubrication film + hole resistance + contact), solved in Python and revolved onto the 3D window. It checks against the 1D consolidation solution and conserves mass to 1e-12, but it is a preview, not the OpenFOAM/FEBio result.

OpenFOAM (out/openfoam/): porous_initial and porous_sealed are single-domain Darcy–Brinkman cases (tissue = porous cellZone) you can run directly with ./Allrun (ESI edition). fluid_template is the fluid side of the coupling.

FEBio (out/febio/oneway/tissue.feb): biphasic neo-Hookean tissue (hex8), rigid drain surface, sliding contact, loaded with the film pressures from the preview model. python -m drainsponge.couple runs the full two-way OpenFOAM ⇄ FEBio loop.

Placeholder inputs: tissue E, permeability and suction are not clinical values yet. Defaults: E = kPa, k = m⁴/(N·s), suction kPa, film 50 µm, residual film under the seal 3 µm (surface roughness).
